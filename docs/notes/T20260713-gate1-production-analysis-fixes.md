## Gate1 で判断を要する論点

### 1. P1↔P3 の遡及方針の非対称性
- P1（係数変更）は既存 `analysis_result` へ遡及しない一方、P3（指標バックフィル）は指標列を既存行へ遡及する。同一行に「係数は旧・指標列は新」の状態が併存しうる。
- 対象列は分離しており計算競合はないが、運用上の整合方針を承認事項とする。実装では両者を連結していない。

### 2. P3↔P6 の実行順序
- P3 のバックフィル対象抽出はダミー行（`document_type_code=120`）を除外しない。
- 本番適用時は **P6（ダミー行削除）→ P3（バックフィル）** の順を前提とする。両計画本文に相互参照がないため、運用手順として明記が必要。

### 3. P1 migration のプレースホルダ業種
- 暫定係数を持たない業種はプレースホルダ値を維持する設計。維持の是非を確認する。

### 4. P2 バリデーションの符号反転挙動（黒字→赤字で常に警告）
- 乖離チェックが PL 科目（営業利益・当期純利益）にも一律適用され、前回→今回で符号反転する正常な業績変動でも比率が負になり、閾値の広狭に関わらず必ず Slack 警告が飛ぶ。意図通りか、対象を BS 系に限定するか／符号反転を別ルールにするかを判断する。

### 5. P1 migration のサイレント0件UPDATE
- `industry.name` 完全一致 UPDATE は表記揺れ時に無言でスキップされ、企業価値算出係数が旧値のまま残る。適用後に `ROW_COUNT()` または「`operating_profit_weight = 10.0000` の残存が想定7件（プレースホルダ）のみか」を検証する手順を適用前後チェックに必須化する。

### 6. 管理エンドポイントの命名とロール
- `/v1/admin/**` は単一ユーザー・単一ロールの認証のみで、`admin` 命名が実アクセス制御レベルと乖離。既存エンドポイントと同じ認可モデルであり新規の権限昇格はないが、ロール分離の要否を判断する。

## DB適用の前提

- migration 実行・手動SQL・バックフィル実走は **すべて Gate1 承認後**に行う。本変更セットはコード・手順の整備のみで、DBへの実適用は含まない。
- 手動SQL手順書（P5 クレンジング・P6 削除）は個人作業領域 `docs/plans/sql/` に置き、リポジトリには含めない。適用時に手元で参照する。
- 指標バックフィルの管理エンドポイント: `POST /v1/admin/analysis/backfill/indicator`（ドライラン: `GET .../preview`）。事前バックアップを切り戻しの前提とする。

## レビュー結果（セキュリティ／品質）

変更セットに対しセキュリティレビューと品質レビューを実施した。

- **セキュリティ**: CRITICAL/HIGH の新規脆弱性なし。SQLインジェクション（Doma のバインド経由）・CSRF（トークン欠如で403を確認）・未認証アクセス（302誘導を確認）・シークレット直書き・金額計算（BigDecimal 一貫）はいずれも問題なし。
- **品質**: 計算ロジック（P4 年換算・P5 正値ガード）と境界値テストは妥当と確認。一方、P3 バックフィルの初期実装に**アーキテクチャ規約違反**（Controller が Specification を直接呼び業務ロジックを保持、コンストラクタ引数が Checkstyle 閾値超過）を検出。

### 是正済み（コミットに反映）
- P3 の業務ロジックを UseCase/Interactor 層へ移動し、Controller は UseCase のみに依存（`ParameterNumber` 超過も解消）。
- バックフィルのループを1件ごとに例外捕捉＋`documentId` 付きログで継続するよう修正。
- `selectIndicatorBackfillTargets.sql` の `document_type_code` をバインドパラメータ化（ハードコード解消）。
- 異常系テスト（スキップ・失敗継続）を追加。

### 適用前後チェック（DB適用時に実施）
- P1: migration 適用後、`operating_profit_weight = 10.0000` の残存がプレースホルダ7件のみであることを確認（表記揺れによるサイレント0件UPDATEの検知）。
- P3→P6: バックフィル実行前にダミー行（`document_id='XXXXXXXX'`）が削除済みであることを確認（コード側の除外は入れていない＝論点2）。
