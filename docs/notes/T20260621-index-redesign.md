## 1. 把握・整理（ステップ 1）

### 解決すべき課題（1 行）

**会社一覧の各行にサマリーKPIバッジ（最新企業価値・割安度・グレアム指数）を行展開で表示し、詳細に飛ばずとも評価の良し悪しを即座に把握できるようにする。**

### 現状の構成

**デスクトップ（index-table.html, 8列固定テーブル）:**

| 列 | フィールド | 備考 |
|---|---|---|
| 証券コード | `code` | 詳細リンク + みんかぶリンク |
| 会社名 | `name` | 詳細リンク |
| 提出日 | `submitDate` | ソート可 |
| 最新企業価値 | `latestCorporateValue` | ソート可 |
| 変動係数 | `coefficientOfVariationToDisplay` | ソート可 |
| 株価平均 | `averageStockPrice` | ソート可 |
| 割安比率 | `discountRateToDisplay` | ソート可 |
| 対象年数 | `countYear` | ソート可 |

**モバイル（カード形式）:** 証券コード・会社名・提出日 + 最新企業価値/割安比率/株価平均/変動係数/対象年数 の dl グリッド

### スコープ確定

| 区分 | 内容 |
|---|---|
| **コア（必ず実装）** | `index-table.html` のみ変更。列再編 + アコーディオン行展開 + KPIバッジ（3枚）+ 詳細リンクボタン |
| **後回し** | グラフ表示（htmx遅延ロード方式で別タスク） |
| **対象外** | Java / DB / YML 変更不要（全フィールドが `CorporateViewModel` に存在） |

### ドキュメント・コードの乖離

- 乖離なし。`fragments/index-table.html` 単一ファイルの変更で完結。
