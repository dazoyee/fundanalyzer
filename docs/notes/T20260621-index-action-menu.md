## 5. 実装（ステップ 5）

### 実装サマリ

- `index-v2.html` の `page-title` fragment をフレックス化し、右端に ⚙ ボタンを追加
- 上部 2 フォームを `<template x-teleport="body">` 内のオーバーレイ（バックドロップ + パネル）へ移設
- スマホ=ボトムシート（`fixed inset-x-0 bottom-0 rounded-t-2xl`）/ PC=中央モーダル（`sm:left-1/2 sm:top-1/2 sm:-translate-*`）
- 旧上部フォームグリッド（行 18-46）を削除

### 設計判断（技術的ポイント）

| 判断 | 理由 |
|---|---|
| `x-teleport="body"` でオーバーレイを body 直下へ移動 | ヘッダー（layout-v2.html）が `backdrop-blur`（backdrop-filter）を持ち、`position: fixed` の containing block を生成するため。ヘッダー内のままだと fixed がビューポート基準にならずモーダルがヘッダー直下に固定される |
| 閉じる ✕ をインライン SVG（lucide:x 相当）に | teleport された要素は app.js の初期 `createIcons`（DOMContentLoaded 時）の対象外。lucide `<i data-lucide>` だと描画されないため。app.js 変更（スコープ外）を避ける目的も兼ねる |
| 開いたら先頭 input へフォーカス（`x-ref` + `$watch` + `$nextTick`） | キーボード操作性の最低限の確保。完全なフォーカストラップは `@alpinejs/focus` の新規依存が必要なため後回し |
